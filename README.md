# Copa 2026

Pagina publica, responsiva e nao oficial com todos os grupos, confrontos, datas, horarios e estadios da fase de grupos da Copa do Mundo 2026.

Site publicado: https://somosnext.github.io/copa-2026-simulador/

## Conteudo

- 12 grupos da Copa 2026.
- 48 selecoes.
- 72 jogos da fase de grupos.
- Horarios convertidos para Brasilia.
- Lista completa por grupo e calendario geral.
- Visual preto e branco.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar build

```bash
npm run build
```

## Deploy no GitHub Pages

O site esta publicado pela branch `gh-pages`.

## Aviso

Este e um projeto nao oficial, sem ligacao com FIFA, organizadores, patrocinadores ou emissoras. As informacoes foram organizadas como guia de consulta publica.
